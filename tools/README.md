# 天然生成のロジック検査

Python 3の標準ライブラリのみを使います。リポジトリ直下から次を実行してください。

```text
python -B tools/test_natural_generation.py
```

`--report result.json`で詳細集計も保存できます。テストはMODの実際の定義を読み、重み付き抽選・条件・フラグ・追加件数を簡易評価します。
Stellarisのエンジンで動作を確認するテストではありません。乱数列、特性追加の内部処理、実際の銀河生成、イベントの発火順序はゲームで別途確認する必要があります。

同梱の`natural-generation-results.json`は2.1.0-beta.3の模擬検証結果です。33,000回の生成と63件の互換性・対象外・再実行等のケースを含みます。
