# MOD定義のロジック検査

## 職業・開発・AIのロジック検査（beta.6）

```text
python -B tools/test_balance.py
```

同梱の`balance-results.json`は9,254ケースの検査結果です。旧造船補正の除去、1枠追加/撤去、AI予算、大学街の比率、メニューの委譲、防衛艦生成のガードを検査します。`python -B tools/test_beta5.py`で追加180ケースを実行し、データマイナー・造船工の効果量と新旧ゲシュタルトの資源特性13種を確認します。
支払い・取消・完了は通常のディシジョンを使う設計ですが、このテストのキューモデルはゲーム本体の実装ではありません。費用補正、返金、取消時・所有者変更時のコールバックは実機で確認してください。

`python -B tools/test_beta6.py`で671ケースを追加検査します。手動取消・自動中止・領有変更・条件喪失・旧版予約・再実行・同一国の複数惑星を確認し、予約処理が独自の支払い/返金を行わないこと、旧シナプス/文化人参照や架空のAI産出見積もりを残していないこと、ゲシュタルトの通常職混入・快適度・ドローン説明の日本語/英語キーを検査します。実際の返金額やAIの建設結果を確認する試験ではありません。

## 天然生成（抽選はbeta.3仕様、beta.5の区域方式フラグを追加）

Python 3の標準ライブラリのみを使います。リポジトリ直下から次を実行してください。

```text
python -B tools/test_natural_generation.py
```

`--report result.json`で詳細集計も保存できます。テストはMODの実際の定義を読み、重み付き抽選・条件・フラグ・追加件数を簡易評価します。
Stellarisのエンジンで動作を確認するテストではありません。乱数列、特性追加の内部処理、実際の銀河生成、イベントの発火順序はゲームで別途確認する必要があります。

同梱の`natural-generation-results.json`は現版の模擬検証結果です。33,000回の生成と63件の互換性・対象外・再実行等のケースを含みます。
